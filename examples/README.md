# What is NXellipsometry?

The [NXellipsometry](https://fairmat-nfdi.github.io/nexus_definitions/classes/applications/NXellipsometry.html#nxellipsometry) NeXus application definition is a standard for converting ellipsometry data to make these FAIR.
